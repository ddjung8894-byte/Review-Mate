# Review Mate

쿠팡 리뷰 작성을 돕는 ChatGPT 프롬프트 생성기입니다.

이 버전은 OpenAI API를 직접 호출하지 않습니다. 별도 API 결제 없이, 사용자가 이미 쓰고 있는 ChatGPT Plus에 붙여넣을 프롬프트를 만들어줍니다.

## 사용 방법

1. 상품명과 사용 메모를 입력합니다.
2. `붙여넣을 프롬프트 만들기`를 누릅니다.
3. `프롬프트 복사하기`를 누릅니다.
4. ChatGPT에 붙여넣어 리뷰를 생성합니다.

## 특징

- API 비용 없음
- 모바일 브라우저 사용 가능
- 리뷰 본문은 소제목 없이 500~700자 사이로 요청
- 사용자의 말투와 유머 감각을 자연스럽게 반영하도록 요청
- GitHub Pages에 올릴 수 있는 단일 `index.html` 웹앱

## 로컬 실행

`index.html` 파일을 브라우저로 열면 바로 사용할 수 있습니다.
