# Review Mate

블로그 글과 리뷰의 ChatGPT 프롬프트를 만들어주는 개인용 웹앱입니다.

이 앱은 OpenAI API를 직접 호출하지 않습니다. 별도 API 결제 없이, 사용자가 이미 쓰고 있는 ChatGPT Plus에 붙여넣을 프롬프트를 만들어줍니다.

## 프리셋

- **블로그 글쓰기**: 당뇨·마운자로 기록, 맛집 후기, 일상글
- **쇼핑 리뷰**: 쿠팡 리뷰

## 사용 방법

1. 홈 화면에서 쓰고 싶은 글의 프리셋을 고릅니다.
2. 재료(메모)를 입력하고 `프롬프트 만들기`를 누릅니다.
3. `프롬프트 복사하기`를 누릅니다.
4. ChatGPT에 붙여넣어 글을 생성합니다.

## 말투 프로필

홈 화면 하단의 `⚙ 내 말투 설정`에서 존댓말/반말, 이모지 사용 빈도, 문장 성격, 소개 한 줄, 항상 지킬 것을 저장할 수 있습니다. 저장된 프로필은 이후 모든 프리셋의 프롬프트에 자동으로 반영됩니다. 프로필은 브라우저 localStorage에만 저장되며, 서버로 전송되지 않습니다.

## 안전 장치 (당뇨·마운자로 기록)

이 프리셋은 개인 기록용입니다. 프롬프트에는 의학적 조언을 요청하는 문구가 포함되지 않으며, 약 권유·용량 조언 금지와 면책 문구를 포함하는 안전 블록이 항상 삽입됩니다. 결과 화면에는 게시 전 확인용 체크리스트가 함께 표시됩니다.

## 특징

- API 비용 없음
- 모바일 브라우저 사용 가능
- 로그인·서버·DB 없음, 저장은 브라우저 localStorage만 사용
- GitHub Pages에 올릴 수 있는 단일 `index.html` 웹앱

## 로컬 실행

`index.html` 파일을 브라우저로 열면 바로 사용할 수 있습니다.
